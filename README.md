# Игра «Крестики-нолики» (Tic-Tac-Toe)

Классическая игра **«Крестики-нолики»** для двух игроков, разработанная на языке **C#** в среде **Microsoft Visual Studio** с использованием технологии **Windows Forms**.

![Игровой интерфейс](image_YVFE_J.png)

##  Особенности проекта
* **Режим игры:** Игрок против Игрока (PvP) за одним компьютером.
* **Игровое поле:** Удобная сетка из кнопок размером `3x3`.
* **Информационная панель:** Отображение текущего хода в реальном времени.
* **Сброс игры:** Возможность мгновенно очистить поле и начать матч сначала.

---

##  Требования и технологии
* **IDE:** Microsoft Visual Studio (2019 / 2022)
* **Язык программирования:** C#
* **Технология:** Windows Forms (.NET Framework / .NET)

---

##  Запуск проекта в Visual Studio

1. **Скачайте исходный код** проекта на компьютер.
2. Откройте **Visual Studio**, выберите пункт *«Открыть проект или решение»* и выберите файл решения **`.sln`** в папке проекта.
3. Нажмите клавишу **`F5`** (или кнопку **«Пуск / Начать отладку»** на верхней панели), чтобы скомпилировать и запустить игру.

---

##  Правила и управление

1. Игра рассчитана на **двух человек**, которые ходят по очереди.
2. Первым делает ход игрок за **Крестики (X)**. Текущий чей ход всегда пишется внизу поля в строке `Ход:`.
3. Чтобы сделать ход, **кликните левой кнопкой мыши** по любой свободной серой квадратной кнопке на поле.
4. Победителем становится тот, кто первым соберет три своих символа в ряд (горизонтально, вертикально или по диагонали).
5. Если все ячейки заполнены, а победитель не определен, объявляется ничья.
6. Нажмите кнопку **«Начать заново»** внизу экрана, чтобы обнулить игровое поле в любой момент матча.

---

##  Ключевые файлы проекта
* `Form1.cs` — содержит код обработки нажатий на кнопки, логику смены ходов (`X` / `O`) и проверку условий победы или ничьей.
* `Form1.cs[Конструктор]` — автоматически сгенерированный код разметки игрового поля, кнопок и текстовых меток.
